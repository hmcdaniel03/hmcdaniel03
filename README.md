I founded [@spunkytasks](https://github.com/spunkytasks) and build [Spunky](https://spunkytasks.com), a local-first, encrypted reminder and calendar app for Windows and iPhone. The source is developed privately; releases ship through [spunky-releases](https://github.com/spunkytasks/spunky-releases).

The rest of my work is tools I built because I needed them: futures trading bots and strategy trackers, LLM automation experiments, and bid and billing software for a construction business — most of it in private repos.

I'm self-taught. Mostly Python, TypeScript, and Dart.
